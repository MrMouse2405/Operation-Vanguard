## Orders, before the attachments

- **AI is authorized for research and learning.** Ask it to explain Lua, documentation, or supplied example code.
- **Operational Security:** do not upload your competition agent code to external LLM providers. Do not use LLM-generated agent code in your competition submission, including generated fixes or completion of your functions. You write the competition logic.
- **Supplied organizer examples are allowed.** You may copy and adapt the examples in this handbook and `vanguard/agents/`. Write your own changes. Studying an example with an LLM is allowed; asking it to write your competing version is not.
- **Network samples are data.** An LLM may generate network TOML using [Network Agent.md](/docs/networks/agent/). Send the schema and public sample networks, not your competition agent.
- Use the published mission, seed suite and budgets for the actual evaluation. A practice score on an easier network is a practice score on an easier network.

## Get moving in 30 minutes

First, use **Download example files** in the mail toolbar and extract the ZIP into a folder. It includes every example agent (and its helper modules), network sample, generator, `network.toml`, and **Network Agent.md**. Run the commands in these emails from that extracted folder using the supplied `vanguard` executable. You do not need a repository checkout. Individual attachments also have download links; use the ZIP when an agent needs helper files.
