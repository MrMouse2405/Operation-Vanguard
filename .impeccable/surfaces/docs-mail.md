# Documentation inbox

Primary target: vandocs/src/lib/Mailbox.svelte
Mode: Read. First-year CS students learn the simulation through friendly emails.

## Direction contract

THESIS: The complete handbook is a working mailbox, with a suggested learning order instead of a documentation tree.
OWN-WORLD: User-pinned Microsoft Outlook: blue application bar, pale gray folder pane, white message list and reading pane, Segoe UI/system sans-serif, fine separators, restrained corners, Lucide icons and shadcn-svelte controls.
STORY: Open the welcome email, follow the learning sequence, browse topic folders, or search all mail for an exact Lua function. Every message has a rank-and-tech sender, a useful subject, plain-language explanations and accurate runnable examples.
FIRST VIEWPORT: Blue app bar with full-mail search; topic folders flush left; ordered sender/subject/preview message list; roomy selected email with sender, recipient, new-tab action and next lesson. No icon rail or global/list footers. The toolbar offers an embedded example-file ZIP. On phones, the inbox and reading pane are separate navigable views.
FORM: User-pinned Outlook mailbox, code-led; seed: none (user supplied).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
