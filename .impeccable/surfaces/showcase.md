# Component showcase

Mode: Operate. Route: `/`. Users browse and interact with the installed
shadcn-svelte component families, using search and category navigation.

## Direction contract
THESIS: A working component collection, following the user's shadcn reference.
OWN-WORLD: User-pinned emerald terminal palette: mint light surfaces, near-black
green dark surfaces, emerald lettering and actions, self-hosted JetBrains Mono,
crisp borders, and a single 45-degree top-right cut.
Shared cuts: 6px compact, 8px standard, 16px large, amplified at the user's request
for a more techy/cyberpunk treatment. Emerald borders and separated
canvas/panel tones; tracked uppercase navigation and gallery labels, monospace
for status/count data. Keep main typography hierarchy, artwork, layouts,
navigation, component APIs, and behavior. No glows or extra chrome.
STORY: See the collection, find a component, try its behavior; connection status
comes from the real Rocket health endpoint.
FIRST VIEWPORT: Compact navigation, restrained title, search and category filters,
then a responsive gallery of interactive examples. Persistent component index
on desktop; an accessible menu on mobile.
FORM: User-pinned shadcn component-gallery convention; seed: none (user-pinned).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
