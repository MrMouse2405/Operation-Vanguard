# Operation Vanguard

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Rust with Rocket; Bun, SvelteKit with adapter-static and Cytoscape in `ui/`;
standalone static SvelteKit documentation mailbox with shadcn-svelte controls
and Lucide icons in `vandocs/`.

## Product Purpose
Run the same supplied Lua program in private router VMs with deterministic fuel
and tick accounting. Provide a local map-first command workspace and a complete
Lua API handbook. The component-gallery page has been removed.

## Operating Context
Startup requires `vanguard --script agent.lua --network network.toml`. Topology is
explicit TOML; agent selection is never a network configuration default. Rocket
serves the UI and prints its URL. Pause, normal-barrier stepping, restart and
reconnection preserve the engine's authority. Startup prints an ASCII Vanguard
banner and the actual web URL. The terminal monitor and its dependencies are removed.

## Brand Commitments
The dashboard follows the user-supplied network-explorer prototype: dark slate
surfaces, emerald health, amber exposure, red compromise and blue server inventory.
Use Lucide icons, readable controls, monospace telemetry, a LAN health overview,
searchable inventory, node evidence and a collapsible telemetry dock.
The documentation has its own user-approved Outlook identity: blue application
bar, pale gray folders, white message surfaces and Segoe UI/system sans-serif.
Teach first-year CS students through friendly, simple, casual emails with
military-rank-and-tech senders, useful subjects and independently linkable lessons.

## Capabilities and Constraints
The frontend is a static build served by Rocket. The engine owns every tick,
task and outcome. Competitors preserve service while eradicating the botnet;
verified full recovery ends scored matches immediately. Unused deadline ticks
receive the recovered state's service/clean fractions for fixed-horizon scoring;
zero compromised alone is insufficient while exposure or service problems remain.
Scoring awards 600 service, 250 security and 150 recovery points. The browser can
inspect truth, but agents receive only their discovered evidence and messages.
The separate VanMail guide replaces Fumadocs and teaches rules, strategy,
all 23 Lua functions and 19 action durations in 43 emails. Its confirmed learning
order runs from first launch, mission and scoring through network/time/sandbox
basics, tasks, scans, shields, recovery and strategy, then teamwork, API reference,
constants and troubleshooting. Learning path, topic folders, all-mail search,
local read/star preferences, previous/next lessons and new-tab links support both
sequential learning and quick lookup.

VanMail opens on a seven-hour competition briefing and generated category index.
It includes a 30-minute starter path, one/two-router tutorials, Interface guide,
Lua guide, runnable solo/coordinated/leader examples, Network Samples with a
generator and topology-only LLM instruction sheet, and a Debug workshop. Supplied
organizer examples may be copied/adapted. External LLMs may explain public examples
and generate network data; competitor agent code cannot be uploaded and generated
agent code cannot be submitted. Build/install instructions are maintainer-only.
ModeWatcher controls light/dark mode. Fenced blocks highlight and copy exact source.
The documentation build emits only one self-contained offline
`vandocs/out/VanMail.html`, including all lessons and downloadable exercise files.

Optional `--dbg` enables seven write-only `dbgguard` calls for bounded per-agent
drawings and attached metadata. Dashboard panes compare two agent-authored views;
drawings are explicitly distinct from truth and discovered evidence. Instrumentation
uses normal fuel and payload charges. Restart clears drawings and retains the flag.
The Basic, Coordinated and Advanced defender baselines use local five-slot patrols;
coordinated variants share source warnings, with Advanced prioritizing servers.
Published seed-1, 300-tick generator fixtures verify Basic at 1,000 total nodes
and Coordinated/Advanced at 10,000; they are not guarantees for arbitrary missions.

The dashboard opens on aggregate LAN health and drills into a Connections graph.
Selecting sidebar hosts locates them on the graph. Detail is bounded to 80 matching
hosts plus up to 80 additional connection endpoints, including peers outside the
active LAN or filters; the inspector retains every relevant connection record.
Large-network performance uses lazy, paginated JSON inspection and telemetry,
indexed host/LAN filtering, immutable projections and live paints capped at 10 Hz.
Every simulation barrier still executes; command and terminal feedback is immediate.
Jobs/connections have 100-record pages, observations 50-record pages, and expanded
JSON collections 100-entry pages. Closed dialogs mount no hidden JSON content.
Seconds/tick sets a minimum total tick duration including computation during
continuous playback; 0 means full speed.
